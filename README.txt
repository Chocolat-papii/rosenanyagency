ROSE NANNY AGENCY — MOCK WEBSITE
================================

Files
- index.html: page structure and content
- style.css: responsive design and styling
- script.js: mobile navigation, FAQ accordion, and WhatsApp enquiry form

How to preview
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. For best results, use a modern browser and an internet connection for Google Fonts.

- Rose pink, navy and cream styling inspired by the supplied flyer
- Responsive layout for mobile, tablet and desktop
- Services section and five-step placement process
- FAQ accordion
- Contact form that prepares an enquiry in WhatsApp
- Floating WhatsApp contact shortcut
